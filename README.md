# AhAi

De website van Elias Cappon: [ahai.be](https://ahai.be).

Een statische site zonder build: HTML, CSS en JavaScript in `site/`, geserveerd door een Cloudflare Worker (`worker/`) die ook "Klikt het?" en het overzicht draait. Online zetten: `npx wrangler deploy` in `worker/`.

Lettertype: [Lexend](https://www.lexend.com), zelf gehost onder de SIL Open Font License (`site/fonts/OFL.txt`).
